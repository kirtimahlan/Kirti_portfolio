# Portfolio Website

A responsive personal portfolio website created for the Portfolio Website Creation Project.

## Files
- index.html — website structure/content
- style.css — responsive design
- script.js — mobile menu and dynamic year

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Before submission
Replace:
- `your-email@example.com`
- GitHub link
- LinkedIn link
- Any project descriptions/links that need to be exact

Then deploy using GitHub Pages, Netlify, or Vercel.
